Ornament Echoes

This project explores how traditional Uzbek ornament and geometric patterns can be translated into a responsive digital environment. Using microphone input and generative coding in p5.js, sound is transformed into movement, colour, distortion, and evolving visual patterns. The work investigates how geometry can communicate rhythm, atmosphere, and emotion, allowing ornament to behave less like static decoration and more like a living sensory space.

Audio Ornament Mesh

The color is taken according to the dominant frequency: 200 red, 400 orange, 600 yellow, 800 green, 1000 blue, 1200 blue, 1400 purple.
